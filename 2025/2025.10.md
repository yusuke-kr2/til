・mainブランチで作業してしまった場合はステージング前なら、普通にgit checkout で作業ブランチに移ってからステージングしたらいい。   
と思っていたがstashのがいい説が出てきて、記事読んでみたり同期と話してみたりしたが最終的に腑におちず。

   ちなみにpushしてしまってから気づいた場合の対処方をここに残して、いつかの自分の助けにしたい。   
   ①p(作業ブランチ)にmainの内容を移す    
   ```  
   git checkout hoge   
   git merge main      
   ```
   ②mainを作業前に移す   
   ```   
   git checkout main   
   git log --oneline #作業前の正しい状態のコミットハッシュを取得   
   git reset --hard<作業前のコミットハッシュ>   
   #mainで作業する前の正しいコミットに戻す   
   ```
   ③正しい内容としてpushしなおす。   
   ```
   git push -f origin main   
   #-fを使う理由   
   #git pushだとリモートmainにある最新コミットよりもローカルmainの履歴が進んでいればpush,進んでいなければpushを拒否する仕組みの中で、この場合は後者であるため-fを使って強制的にpushしている。   
   ```
   ④pの内容を新しくpush   
   ```
   git push origin p   
   ```
