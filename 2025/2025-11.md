①migrationを作成   
`docker compose exec web rails g migration AddAvatarToUsers avatar:string    
②migrationファイルを確認   
①で作成されたdb/migrate/****_add_avatar_to_users.rbを開いて   
def change   
  add_cokumn :users, :avatar, :string   
end   
になっているか確認   
③migrationを実行   
docker compose exec web rails db: migration     
   
・Avatarという名前のuploaderを作成    
①gem 'carrierwave'   
bundle install   
を実行   
②uploader作成   
'docker compose exec web rails g uploader Avatar   
を実行することで   
app/uploaders/avatar_uploader.rb   
が作成される   
③Userモデルにmount_uploader を追記   
app/models/yser.rbに   
mount_uploader :avatar, AvatarUploader    
を追記    
→これでUser.avatarに画像がアップロードされたときにAvatarUploaderが使われるようになる   
④default_urlを設定   
app/uploaders/avatar_uploader.rbに   
def default_url   
  'sample.jpg'   
end   
を追記
